The writing studio for Obsidian.

Binder, snapshots with side-by-side compare, inspector, corkboard, timeline, research, and compile. One plugin with switchable modules. Everything it adds is stored as Markdown, frontmatter, and git commits, so nothing needs Longhand to be read.

Write, snapshot, compare, restore.

Before a risky edit, take a snapshot and give it a name. That is one git commit for one file, and you never see git. When the edit goes wrong, open the Snapshots tab: only this document's named snapshots are listed, not every auto-commit in the vault. Compare shows the old version beside the live text with changes tinted at the word level. Pull back a sentence, or restore the whole thing. Restore snapshots the current state first, so nothing is ever the last copy.

If you are coming from Scrivener, the importer replays every snapshot you ever took as history with its original title and date. You arrive with your past intact.

What changes in Obsidian

The file tree becomes a binder.
An ordered manuscript you drag to reorder. Folders are chapters, folder notes are chapter text.
The properties panel becomes an inspector.
Synopsis, label, status, notes, keywords, bookmarks, and attached research beside what you are writing.
Raw commits become named snapshots.
Per document, with compare and safe restore.
Three plugins become one view.
Corkboard, kanban, and timeline read the same synopsis, label, status, and date fields.
Research stays with the scene.
PDFs, images, and notes attached to the document you have open. Highlights link back.
Compile means a manuscript.
Presets for short story, novel, poem, essay. Docx, pdf, epub, or Markdown. Your files are untouched.

Works with how you already sync

Longhand does not sync anything. Your vault keeps moving through iCloud, Dropbox, Obsidian Sync, Syncthing, or a git remote, whichever you use today. Snapshot history is stored as plain files inside the vault by default, so it travels with the vault to every device, including your phone. If you want real version control as well, turn on the git store: desktop only, and the repository is kept outside the synced folder so cloud sync never touches it.

Get it

Coming from Scrivener

The importer turns a .scriv package into a vault that follows the Longhand spec, snapshots included. Your Scrivener project is never modified.

go install github.com/grassclaw/scrivener-to-obsidian/cmd/scriv2obsidian@latest
scriv2obsidian convert -out ~/Writing -git Novel.scriv

The plugin
