# Code of Conduct

Longhand has adopted the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1, as its Code of Conduct. Everyone who takes part, contributors, maintainers, and users, is expected to follow it.

## Reporting

Report unacceptable behaviour to the maintainer, [@grassclaw](https://github.com/grassclaw), by direct message on GitHub. Reports are handled confidentially.
